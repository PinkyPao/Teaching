# Introduction to R

Teaching materials for the Introduction to R course taught at the University of Southern Denmark (SDU) International Summer School 2026.

The course provides a hands-on introduction to R and RStudio, with an emphasis on learning how to work with, explore, visualize, and analyze real-world data. The materials are designed for students with little or no previous experience with R.

Course content

The course covers:

* Fundamentals: Getting started with R and RStudio
* Data Structures in R
* Conditions, Functions, and Loops in R
* Packages in R
* Data wrangling with tidyverse
* Data visualization with plot and ggplot2
* Descriptive statistics
* Intro to linear regression

Repository structure

The repository contains the materials used throughout the course, including:

* Class notes – Notes and examples used during the lectures

Using the materials

You are welcome to use, share, and adapt the materials with appropriate attribution.

The examples are intended to be run interactively in R/RStudio. Some exercises use external datasets, so make sure the corresponding data files are available in your working directory before running the code.
